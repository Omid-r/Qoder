# Product Requirements Document (PRD) — Qoder (Splunk Infrastructure Studio)
- **Controlled Discovery:** Strict CIDR allowlisting, exclusion enforcement for sensitive OT/printer networks, and zero exploitation.
- **Live Topology Mapping:** Real-time visualization of discovered Linux/Windows hosts, firewalls, and Splunk components with observed vs. inferred edges.
- **Architecture Studio:** Interactive Splunk Validated Architecture (SVA) calculator based on daily ingest (GB/day), retention, HA/multisite requirements, and replication/search factors.
- **Best Practices Engine:** Version-aware OS & Splunk tuning (e.g., THP disable, ulimit, SmartStore) with Dry-Run diff preview.
